# Ferry · макеты интерфейса (фаза 0)

Одиннадцать экранов из §11 проектного документа в стиле «судовая накладная».
Статический HTML: ни сети, ни шифрования, ни файлов — только интерфейс и переключаемые
состояния. Это то, что §13 называет фазой 0, и то, из чего вырастает `Server/web/`.

Открывать можно прямо с диска: `index.html` → любой экран. Сборка не нужна.

## Что где лежит

```
ferry-mockups/
├── index.html              список экранов, он же точка входа
├── assets/
│   ├── tokens.css          переменные дизайн-системы Ferry, обе темы
│   ├── ferry.css           слой компонентов: лист, секции, карта тома, таблицы
│   ├── ferry.js            тема, панель макета, сценарии, рендер карты тома
│   └── fixtures.js         фейковые данные: том, манифест, коды ошибок
└── screens/
    ├── s1-empty.html       S1 · пустой экран, дропзона
    ├── s2-setup.html       S2 · настройка раздачи (контролы живые)
    ├── s3-active.html      S3 · активная раздача — главный экран продукта
    ├── s4-approval.html    S4 · запрос доступа (модалка)
    ├── s5-owner-leave.html S5 · уход владельца (модалка)
    ├── r1-preview.html     R1 · превью тома
    ├── r2-destination.html R2 · куда сохранить, три пути записи
    ├── r3-download.html    R3 · приём тома, две волны
    ├── r4-reconnect.html   R4 · обрыв и возобновление
    ├── r5-done.html        R5 · готово
    └── errors.html         E  · девять кодов протокола из §8
```

## Три слоя, и только один из них выбрасывается

| Слой | Что это | Судьба в фазе 1 |
|---|---|---|
| `tokens.css` | переменные из дизайн-системы Ferry | остаётся как есть; регенерируется из `tokens.json` |
| `ferry.css` | компоненты: `.f-sheet`, `.f-section`, `.f-vmap`, `.f-trow`, `.f-stamp` | остаётся; классы переезжают в React-компоненты один в один |
| `ferry.js` + `fixtures.js` | панель макета, фейковые сценарии, крошечный биндинг | **выбрасывается целиком** |

Разметка экранов не выбрасывается: она и есть JSX будущих компонентов.

## Как читать разметку

Никакого фреймворка нет. `ferry.js` умеет ровно пять вещей, и все они называются
`data-`атрибутами:

```html
<span data-f="rate"></span>                      <!-- textContent = model.rate -->
<i data-style="width:wave1w"></i>                 <!-- style.width = model.wave1w -->
<div data-if="twoWaves">…</div>                   <!-- скрыть, если ложно; data-if="!x" — наоборот -->
<span data-class="stampClass">…</span>            <!-- добавить класс из модели -->
<div data-list="receivers"><template>…</template></div>  <!-- повторить по массиву -->
<div data-vmap="map">…</div>                      <!-- карта тома из model.map -->
```

Модель экрана собирается в `<script>` внизу файла функцией сценария и целиком
соответствует будущим пропсам:

```js
{ rate: '112,4', pct: '54 %', twoWaves: true,
  map: { segments: ['have','have','peer',…], cursors: [{x:'42%', name:'Марк', catching:true}] },
  receivers: [{ name:'Костя', w1:'90%', pct:'90 %', role:'качает', roleClass:'f-role--leech' }] }
```

При переносе в React: `data-f` → `{model.rate}`, `data-if` → `{cond && …}`,
`data-list` → `items.map(…)`, `data-vmap` → компонент `<VolumeMap segments cursors />`.
Имена полей менять не нужно — они уже совпадают с §8 (`ranges`, `have`, `peers`, `state`).

## Панель макета

Верхняя полоса с пунктирной линией — инструмент, в продукте её нет. Она переключает
тему (сохраняется в `localStorage`) и сценарии из §13: «трое, один отстал», «третий
подключился на 60 %», «отправитель ушёл», «мало места», «пароль», «ссылка мертва» и
все девять кодов ошибок. Чтобы убрать панель, достаточно удалить `<div class="f-proto">`
и вызов `Ferry.screen` — экран останется рабочим на статических данных.

## Что уже соблюдено из дизайн-системы

- Обе темы равноправны: светлая по умолчанию, тёмная — `data-theme="dark"` на `<html>`
  или системная настройка. Ни одного литерального цвета вне `tokens.css`.
- Кириллица во всех начертаниях, IBM Plex Sans и Mono с Google Fonts.
- Живые числа — `mono-num` с табличными цифрами; единицы измерения набраны `ink-300`
  рядом с числом цвета `ink-100`.
- Пять состояний чанка на карте тома разведены по яркости и читаются в оттенках серого.
- Ни одного статуса, переданного только цветом: рядом всегда слово.
- Скругления: `radius-0` у всего, что измеряет, `radius-md` у кнопок и полей.
- Фокус клавиатуры — сплошное кольцо `focus` с отступом 2px, нигде не снято.
- Honest-оговорки стоят рядом с контролами: пароль, работа без владельца, место на диске,
  невозможность сидировать на последовательном пути.
- Узкая раскладка: всё складывается в одну колонку от 360px, лишние колонки таблиц
  прячутся, карта тома остаётся во всю ширину.

## Чего в макетах намеренно нет

- Настоящего QR: `Ferry.qr` рисует похожий квадрат. В фазе 1 сюда встаёт кодер ссылки.
- Виртуализации списков: опись показывает 6 строк из 4 812. Дерево на 100 000 записей —
  задача фазы 4, в макете обозначено подписью.
- Анимации прихода чанков сверх 240ms перекраски: карта «едет» раз в 700 мс тиком макета.
- Любых вычислений: проценты, скорости и ETA — это строки в `fixtures.js`.
